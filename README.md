### 개념

코딩을 직접하지는 말 것. ai와 협업해서 새로운 프로그램을 만들자

#### 기존 개발 방법

요구사항 분석 -> 설계(DB/UI) -> 구현/디버깅 -> 테스트 -> 배포 -> 유지보수

### 바이브코딩 방식

요구사항정의(PRD) - ai가 코드 생성/디버깅, 테스트 -> 사람 **검증** 수정요청, 직접수정 -> 배포

-> AI유지보수

#### 핵심 포인드

- ai - 주니어/시니어 개발
- 사람 - pm + 리뷰어
